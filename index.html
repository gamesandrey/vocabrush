VOCABRUSH

Aprende vocabulario mientras sobrevives a plataformas en movimiento

VocabRush es un juego educativo de plataformas diseñado para aprender vocabulario de forma interactiva y divertida. En cada ronda se te muestra una palabra y debes saltar a la plataforma que contiene su significado correcto antes de que el tiempo se agote. Puedes elegir la dificultad, acumular puntos y mejorar tu habilidad mientras entrenas tu memoria de palabras sin darte cuenta.

Sobre el proyecto

VocabRush ha sido desarrollado como un proyecto educativo interactivo que combina programación, diseño de videojuegos y aprendizaje de idiomas. El juego está construido con tecnologías web:
  • HTML para la estructura
  • CSS para el diseño visual y la interfaz
  • JavaScript para toda la lógica del juego (movimiento, físicas, rondas, puntuación y sistema de vocabulario)
El objetivo del proyecto es demostrar cómo un videojuego puede convertirse en una herramienta de aprendizaje activa, donde el jugador no memoriza de forma pasiva, sino que aprende a través de la acción, la repetición y la toma de decisiones bajo presión.

Cómo ayuda a aprender vocabulario

Este juego mejora el aprendizaje porque:
  • Repite palabras en diferentes contextos
  • Obliga a reaccionar rápido, reforzando la memoria
  • Asocia significado con acción, no solo lectura
  • Usa el error como parte del aprendizaje
  • Motiva a mejorar puntuación y rendimiento

Objetivo

El objetivo de VocabRush es convertir el estudio de vocabulario en una experiencia dinámica, donde aprender se sienta como jugar, y no como memorizar.
